# anthropics/skills

## What This Page Is For

Frame `anthropics/skills` as a reference set for conventions, structure, and examples rather than a source to copy mechanically.

## When To Use This

Use this page when you want to see how a skills library can be organized and what good examples tend to look like.

## If You Only Remember One Thing

Treat `anthropics/skills` as a reference implementation. Reuse the ideas that fit your workflow, but do not copy the repository blindly into a different agent or packaging model.

## What You Can Learn From It

- how skills are named and grouped
- how example content stays focused on one job
- how a library can be organized without turning into a dump of unrelated instructions

## How To Use It Well

Use the repository to study patterns, then map those patterns to your own agent, install path, and workflow layer. If the example assumes a different activation model or packaging story, keep the convention and adapt the mechanics.

That is the useful part of a reference library: it shortens the distance between "I need a skill" and "I know what shape that skill should have".

## What This Is Not

- not the whole ecosystem
- not a substitute for local workflow guidance
- not a reason to mirror upstream details that are specific to Anthropic's tooling
